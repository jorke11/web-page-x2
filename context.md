# Contexto X2 App

## Descripción del Producto
X2 es un software de gestión integral para lavaderos de vehículos, talleres de mecánica y detailing. Administra órdenes, registra gastos, maneja clientes, vehículos e inventario. Para negocios con tienda o restaurante básico, incluye gestión de inventario con compras, bajas, recetas, mesas y kardex.

## Módulos Principales
- **Gestión de Órdenes**: Registro completo de servicios
- **Módulo de Tienda/Restaurante**: Inventario, recetas, mesas, kardex
- **Módulo de Parqueadero**: Vehículos categorizados por precios/planes
- **Facturación Electrónica**: Para Colombia (DIAN)
- **Liquidación de Trabajadores**: Por servicio prestado
- **Gestión de Nómina**: Para personal administrativo
- **Reportes en Tiempo Real**: Ventas, gastos, trabajadores
- **Visualizador de Órdenes**: Pantalla para clientes
- **WhatsApp**: Notificaciones de apertura/cierre de caja, estado de orden
- **Portal del Cliente**: Reservas, seguimiento de cuotas para obsequios
- **MCP con IA**: Gestión por voz, datos generados por IA, accesibilidad
